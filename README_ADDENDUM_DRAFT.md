# High-Sight — README Explanation Draft

## In plain language

A concept for helping people notice how long they use screens and remember to take regular breaks.

## Current status

Concept-stage: no executable application is committed yet.

## Proposed first version

A user starts a timer, records a break and optionally receives a reminder. The first version should not monitor the screen or camera.

## Technical direction

Begin with a local-only session state model, accessible timer UI, configurable reminders and export/delete behavior. Record dependencies, supported platforms and test commands once the first runnable slice exists.

## Safety and privacy

This is not a medical device and does not diagnose or treat eye conditions. Avoid hidden monitoring, camera use or collection of browsing/app activity.

## Contributing

Start with FEATURE_UPGRADE_PLAN.md and CONTRIBUTING.md. No implementation is claimed until it is committed and tested.
