# High-Sight

**A concept for healthier screen habits and eye-strain awareness.**

[![License](https://img.shields.io/badge/license-see%20LICENSE-lightgrey)](LICENSE)

High-Sight is an early project concept for helping people notice screen-use patterns and adopt healthier display habits.

## Intended Direction

- Track screen-session duration and break intervals.
- Offer reminders for regular breaks.
- Let users record discomfort or fatigue patterns.
- Provide simple personal summaries of screen habits.

## Current Repository State

This repository currently contains a README and license only. No screen-monitoring, eye-tracking, diagnostic, or health-assessment code has been committed.

## Safety Note

High-Sight is not a medical device and must not claim to diagnose, prevent, or treat eye conditions. Any future guidance should be general wellness information and should direct users with persistent symptoms to a qualified eye-care professional.
