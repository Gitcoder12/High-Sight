# High-Sight — Feature Upgrade Plan

## Objective

A concept for helping people notice how long they use screens and remember to take regular breaks.

## Stage 0 — scope and privacy

- [ ] Confirm a user problem and intended audience.
- [ ] Define a minimal data model and threat/privacy review.

## P0 — first runnable vertical slice

- [ ] Choose a narrow first user workflow and define what data is collected before writing monitoring code.
- [ ] Create a local-only session timer and manual break log; do not add screen surveillance or camera/eye tracking.

## P1 — usability

- [ ] Add configurable reminders, snooze and accessible quiet hours.
- [ ] Provide local export/delete controls and a clear privacy summary.

## P2 — optional research

- [ ] Evaluate reminder usefulness with opt-in feedback and transparent retention.
- [ ] Only explore sensor/device integrations after a separate privacy and safety review.

## First milestone acceptance

- [ ] User can start/end a manual focus session.
- [ ] Reminder settings can be changed and reset.
- [ ] Data is local, visible and deletable.
- [ ] No diagnostic or surveillance claim is made.
