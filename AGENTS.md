# Agent Instructions — High-Sight

This is a concept-stage repository. Read the roadmap before creating implementation.

- Do not claim unimplemented features exist.
- Start with a local, manual session timer and break log.
- No hidden monitoring, camera use, eye tracking or medical assessment.
- Minimise personal data and provide clear delete/export behavior.
- Add tests for settings, timer state and persistence before expanding scope.
- Work on a branch and open a PR; do not merge or deploy autonomously.
