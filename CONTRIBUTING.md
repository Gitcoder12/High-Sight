# Contributing to High-Sight

This is a concept-stage project. First propose a narrow, privacy-first user workflow before adding features.

1. Read README.md and FEATURE_UPGRADE_PLAN.md.
2. Open or select an issue with a user problem and acceptance criteria.
3. Work on a feature branch.
4. Add accessible, deterministic tests and documentation.
5. Minimise data collection; make all collection visible and optional.
6. Open a PR with exact validation results and limitations.

Do not add hidden screen/app monitoring, camera/eye tracking, medical diagnosis or telemetry without a separate approved design and privacy review. Human maintainer approval is required.
